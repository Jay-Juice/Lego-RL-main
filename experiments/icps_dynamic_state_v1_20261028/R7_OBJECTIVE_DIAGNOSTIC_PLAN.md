# Post-score objective alignment diagnostic

The completed joint experiment lost coverage under a new global lexical set objective. Without changing any method, compare that same objective on emitted control and new windows for each of607 existing development inputs. Aggregate higher/equal/lower objective counts and, separately, paired visible/full gains/losses by those signs. Verify total gains/losses against the completed aggregate. This is scorer-only, after outcomes are known; it is not a new independently tested hypothesis or a selector. Do not export per-case information or use it to tune parameters. No R6 confirmation. It distinguishes objective-increasing losses from cases where approximate search/proposal pruning did not even improve the objective; it does not isolate individual feature causation. The same-score lookahead experiment is separately frozen and continues unchanged.
